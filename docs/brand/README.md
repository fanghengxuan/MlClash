# 品牌资源

MlClash 的长期品牌形象：**Merlin 魔法师 + Clash 猫咪 + 路由器**。

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `mascot.png` | 1254×1254，透明 | 原始吉祥物 |
| `logo.png` | 512×512，圆角深色底 | 应用图标、面板 favicon、软件中心图标 |
| `avatar.png` | 512×512 | GitHub 账号 / 组织头像 |
| `hero.jpg` | 2400×840 | README 头图 |

更新品牌形象时，请同步替换：

- `cmd/mlclash-panel/web/icon-256.png`（面板 favicon / apple-touch-icon）
- `plugin/res/icon-mlclash.png`（路由器软件中心图标）

视觉基调保持深蓝黑背景与青蓝渐变，不再频繁更换方向。
