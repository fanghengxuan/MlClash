## 3. 判定

**未发现内存泄漏。**

- 面板 RSS 相比静置前基线只高约 1.1–1.3MB，静置 3 分钟后稳定在 13.6–13.9MB，没有持续增长。
- fd 在并发期瞬时到 34，压力结束后回到 13，SSE 连接没有泄漏。
- 线程从 9 增到 12 后保持不变；Go runtime 保留少量额外 OS 线程属正常，不是压力期持续增长。
- 内核 RSS 在重载/重启瞬间上探到约 55MB，最后一次重启后回到 48.5MB，与基线基本一致。
- `mihomo -t` 子进程、`.tmp` 文件、iptables 规则数均无累积。
- 压测后引擎 `running=true`、`wanted=true`，代理出口 `18.140.58.98`，国内直连 `101.68.142.6`，设置/订阅/规则均恢复基线。

## 4. 说明

- 本轮为单次约 13 分钟的集中压测，未做数小时 soak；从 RSS 静置曲线看没有泄漏趋势。
- 采样中的“基线”若取并发开始时，fd/线程会略高于真正的静置基线，因此本报告同时列出静置前的手工基线与压力峰值。
- 压测期间路由器负载短暂升至约 2.0（`mihomo -t` 校验 + 热重载 + 节点测速），结束后回落。
